# Phone Scroll 3D (R3F)

بروجكت React Three Fiber بيعرض موديل تلفون 3D فوق الصفحة، يظهر بأنيميشن سموز أول
ما الصفحة تفتح، وبعدين مع السكرول ينزل تدريجيًا للقسم التاني ويختفي.

## طريقة التشغيل

1. حط ملف الموديل بتاعك في مجلد `public` وسمّيه بالظبط:
   ```
   public/phone.glb
   ```
   (لو اسمه مختلف، غيّر قيمة `MODEL_PATH` في `src/Phone.jsx`)

2. ثبّت المكتبات:
   ```bash
   npm install
   ```

3. شغّل السيرفر المحلي:
   ```bash
   npm run dev
   ```

4. افتح الرابط اللي هيظهر في الترمينال (غالبًا http://localhost:5173)

## هيكل الملفات

- `src/Phone.jsx` — الكومبوننت المسؤول عن تحميل الموديل، أنيميشن الظهور
  (Intro)، وحركة السكرول. **كل القيم اللي تقدر تعدلها متجمعة فوق في الملف
  تحت كومنت `🔧 القيم اللي تتحكم في حركة التلفون`.**
- `src/App.jsx` — الصفحة نفسها: فيها الكانفاس (القسم الأول) والنص التجريبي،
  وتحته القسم التاني اللي التلفون بينزل عليه. عدّل النصوص هنا زي ما تحب.

## أهم القيم اللي ممكن تلعب بيها (في `Phone.jsx`)

| المتغير | وظيفته |
|---|---|
| `INTRO_DURATION` | مدة أنيميشن الظهور الأولاني |
| `INTRO_START_SCALE` / `INTRO_TARGET_SCALE` | حجم التلفون قبل وبعد الظهور |
| `SCROLL_MOVE_DISTANCE` | مسافة نزول التلفون مع السكرول |
| `SCROLL_SCALE_END` | حجم التلفون وهو خالص نازل |
| `SCROLL_ROTATION_Y` | لفة التلفون مع السكرول (خليها 0 لو مش عايزها) |
| `SCROLL_FADE_START` | بعد أد ايه من السكرول يبدأ التلفون يختفي |

## ملاحظات

- لو موديل التلفون كبير أو صغير جدًا في المشهد، البادئة الأسهل إنك تعدّل
  `INTRO_TARGET_SCALE` في `Phone.jsx` بدل ما تعدّل الموديل نفسه.
- الكانفاس شغال بـ `position: fixed` عشان يفضل ظاهر فوق الصفحة وهي بتتسكرول،
  وده اللي بيدي إحساس إن التلفون "بينزل" مع الصفحة.
